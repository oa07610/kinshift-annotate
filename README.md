# KINSHIFT annotator dashboard

Static page served by GitHub Pages, in English and Urdu (switch at the top of every
page). Volunteers sign in with their name, go through onboarding (the guidelines, part by
part, with short questions), then give their language's words for 150 relatives. Answers
are kept in the browser and sent to the KINSHIFT team's server automatically.

The source of this page, the build scripts and the merge tools live in the project's
private repository; this repository is generated from it.
