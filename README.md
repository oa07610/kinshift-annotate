# KINSHIFT annotator dashboard

Static page served by GitHub Pages. Annotators sign in with a handle and access
code, work through the rounds, and export a file per batch that they send to the
KINSHIFT team. Nothing is uploaded; answers live in the annotator's browser until
exported.

Later-round batches contain benchmark items and are encrypted per annotator with
their access code, so this public repository never exposes them in plain text.

The source of this page, the build scripts and the merge tools live in the
project's private repository; this repository is generated from it.
